Dexion is a high-speed, precision-focused trading terminal built for the Stacks blockchain. It provides wallet tracking, bonded token discovery, automated limit orders, portfolio analytics, and more—all through a non-custodial interface.

## Key Features

- **Wallet Tracking** – Monitor up to 300 wallets with live portfolio stats.
- **Bonded Token Discovery** – Instantly detect and act on new bonding events.
- **Limit & Market Orders** – On-chain execution, off-chain precision.
- **Telegram Bot** – Real-time alerts, mobile trading, sniping.
- **Portfolio Analytics** – PnL tracking, allocations, multi-wallet aggregation.
- **CA Sniping** – Automated entry into early-phase tokens.
- **Multi-source Token Search** – Filter tokens by bonding %, liquidity, and source.

## Built for Traders

Dexion is optimized for:
- High-frequency snipers
- On-chain alpha hunters
- Portfolio managers
- Power users who demand speed, visibility, and control

> Trade fast, stay informed, stay in control.
